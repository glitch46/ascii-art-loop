# ASCII Art Loop

A minimal black page displaying the animation from [0xSero's post](https://x.com/0xSero/status/2116252586961698900). The original artwork and video are by 0xSero; the related dot-lattice tools are available at [0xSero/ascii-art](https://github.com/0xSero/ascii-art).

Open `index.html` in a browser, or serve this directory as a static site. The video is muted so it can play automatically and loops continuously. A CSS filter brings the original charcoal background to black.
